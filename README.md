# AegisShare Frontend

**Stack:** React 18 · TypeScript · Vite · Tailwind CSS · Zustand · React Router v6

**Purpose:** Zero-knowledge, compliance-first secure file-sharing platform

**Design System:** Playfair Display · JetBrains Mono · Plus Jakarta Sans · Deep navy-obsidian palette

## Compliance

- GDPR
- HIPAA
- SOC 2
- CCPA
- ISO 27001

## Quick Start

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
npm run preview
```

## Testing

```bash
npm test
npm run test:ui
npm run coverage
```
